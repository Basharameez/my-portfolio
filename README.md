### 02 / RotorDyn — Industrial Vibration Telemetry & FFT Diagnostics SaaS
> **Client SaaS System** • *Python, FastAPI, Plotly.js, Fast Fourier Transform (FFT)*

* **Problem**: Industrial manufacturing machinery requires real-time telemetry processing to detect bearing fatigue (BPFO/BPFI defects) before catastrophic failure occurs.
* **Engineering Solution**: Developed backend API processing microservices for Fast Fourier Transform (FFT) signal analysis, RMS vibration velocity calculation (mm/s), and ISO 10816 severity zone classification.
* **Production Evidence**: Delivered real-time interactive FFT frequency spectrum visualizations rendering 4,096-line spectral resolution with defect peak markers.

### 03 / BioRobust (BioVision-Path) — Explainable Biomedical Computer Vision Framework
> **Experimental ML Research** • *PyTorch, ResNet-18, PathMNIST, Grad-CAM, ECE Calibration*

* **Problem**: Neural vision classifiers in medical diagnostic pipelines suffer severe accuracy drops under real-world image corruptions (blur, noise, defocus).
* **Engineering Solution**: Built a PyTorch benchmark framework evaluating ResNet-18 accuracy across 35 perturbation conditions on 7,180 PathMNIST tissue slices. Integrated Grad-CAM gradient overlays and Expected Calibration Error (ECE) calculation.
* **Production Evidence**: Verified **39 / 39 PyTest tests passed**. Measured $73.66\%$ baseline clean accuracy, $0.0782$ ECE calibration, and benchmarked worst-case $11.80\%$ accuracy drop under severe blur.
* **Links**: [Repository](https://github.com/Basharameez/BioVision-Path) • [HuggingFace Space](https://huggingface.co/spaces/BASHARAMEEZ/BioVision-Path)
